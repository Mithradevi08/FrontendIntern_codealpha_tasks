## Image Gallery

Developed a responsive image gallery with a dark-themed interface using HTML, CSS, and JavaScript. Users can explore images through category filters and search functionality.

**Technologies:** HTML, CSS, JavaScript

**Features:**
- Image gallery with multiple categories
- Search images by title
- Category-based filtering
- Image navigation and lightbox view
- Hover effects and smooth transitions
- Responsive layout
